# 🛍️ Dumbmerch Backend

Frontend aplikasi **Dumbmerch**, dikembangkan sebagai project bootcamp **Dumbways Indonesia**.  
Repo ini berisi UI untuk e-commerce sederhana yang terhubung dengan backend Dumbmerch.

---

## 🚀 Tech Stack
- **React.js / Next.js** 
- **Axios / Fetch API** → komunikasi dengan backend
- **TailwindCSS / Bootstrap** → styling
- **Docker Compose** → deployment

---

## ▶️ Cara Menjalankan

1. Clone repository:
   ```bash
   git clone https://github.com/abimsyaefulloh/fe-dumbmerch.git
   cd fe-dumbmerch
   ```
2. Jalankan dengan Docker Compose:
   ```bash
   docker-compose up -d
   ```
3. Service akan otomatis berjalan di:
   ```bash
   - Frontend: http://localhost:3000
   ```
4. Author  
   Bootcamp Project – Dumbways Indonesia
